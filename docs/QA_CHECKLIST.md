# QA CHECKLIST

## Desktop checks

- [ ] `npm run validate:models` が通る
- [ ] オンボーディングが初回のみ表示される
- [ ] 「カメラを許可する」導線が見やすい
- [ ] カメラ許可で表情認識が開始される
- [ ] カメラ拒否時に日本語の復旧案内が出る
- [ ] 「もう一度カメラを確認」で再試行できる
- [ ] 「あそび方」から練習画面を開ける
- [ ] 練習画面で 1 表情ずつ確認できる
- [ ] タイトルの各ボタンが押しやすく動作する
- [ ] 着せ替え画面のキャラ / 背景切り替えが動作する
- [ ] ガチャ画面の表示と結果メッセージが自然な日本語になっている

- [ ] 表情認識が使えないときに非ブロッキング案内が出る
- [ ] 結果画面で 共有 / もう一度 / タイトルへ が動作する
- [ ] プライバシー画面の文言が実装と一致している
- [ ] 設定とデータ画面からチュートリアルリセットが動作する
- [ ] 設定とデータ画面からデータリセット確認が動作する

## iPhone checks

- [ ] アプリが横画面専用で起動し、縦向きに回転しない
- [ ] `UIRequiresFullScreen = true` の前提でフルスクリーン表示される
- [ ] iPhone の「設定」→「表情ランナー」→「カメラ」が ON になっている
- [ ] 初回起動時のオンボーディングが短く分かりやすい
- [ ] カメラ許可ダイアログの前に日本語説明が出る
- [ ] 初回インストールでカメラ許可を ON にすると表情認識まで進める

- [ ] カメラ拒否後、設定で ON にして「もう一度カメラを確認」で復帰できる
- [ ] カメラ拒否後、必要なら TestFlight アプリを削除 / 再インストールして再許可できる
- [ ] 実機で笑顔 / 怒った顔 / 驚いた顔 / 悲しい顔が認識される
- [ ] 表情認識が不安定でもタップ操作で最後まで遊べる
- [ ] カメラ失敗時に `診断情報を表示` から詳細を確認できる
- [ ] model 読み込み失敗時に `診断情報を表示` から candidate / fetch / XHR の結果を確認できる
- [ ] shard の byte 数が `3652 bytes` 前後になっていないことを確認できる

- [ ] HUD の文字が小さすぎない
- [ ] タッチボタンが押しやすい
- [ ] 結果画面のボタンが押しやすい
- [ ] 共有フローが動作する
- [ ] アプリを再起動しても保存データが維持される
- [ ] チュートリアルリセット後、次回開始時に練習が再表示される
- [ ] データリセット後、初回状態に戻る
- [ ] 機内モードまたは不安定な通信環境でもアプリが使える
